# Security policy

## Supported state

Version 3.7.12 is a private release-readiness candidate. It is not yet a supported public release.

## Reporting

Do not post a suspected vulnerability, sensitive URL, authentication detail, or private diagnostic report in a public issue. Use GitHub private vulnerability reporting after the repository is published; until then, contact the maintainer privately through the profile contact channel.

## Product boundary

Media Scout does not decrypt DRM, defeat encryption, bypass authentication or paywalls, circumvent signed URLs, evade CORS, or work around access controls. Unsupported and ambiguous media paths fail closed. A report about those deliberate boundaries is not a request to implement bypass behavior.
