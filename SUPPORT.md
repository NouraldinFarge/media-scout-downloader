# Support

Media Scout Downloader is public source under the MIT License, but `3.7.13` remains an unreleased prerelease. There is no supported public binary, Chrome Web Store listing, response-time guarantee, or compatibility SLA.

## Before opening an issue

1. Reproduce the behavior in a disposable browser profile with content you own or are authorized to test.
2. Record the source version or commit and exact browser/operating-system versions.
3. Replace real URLs, titles, filenames, account details, extension IDs, paths, and media with controlled or synthetic values.
4. Inspect any diagnostic preview and share only the minimum evidence required.

Use the repository's bug or feature form for ordinary public discussion. Use [GitHub private vulnerability reporting](https://github.com/NouraldinFarge/media-scout-downloader/security/advisories/new) for security defects, permission-boundary failures, or sensitive-data exposure. Never attach an unredacted report to a public issue.

Requests to retrieve unauthorized content, defeat DRM or encryption, bypass authentication or paywalls, evade CORS, or scrape hidden identifiers are outside the project boundary.
